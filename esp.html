From a single sensor to a full web server

Nine ready-to-flash ESP8266 sketches: three basic sensor readers, four self-hosted web control panels, and a two-board Wi-Fi messenger. Copy, fill in your Wi-Fi name and password, and upload.

Pin names such as D1–D8 are the Wi-Fi shield / NodeMCU labels, mapped by the board package to the real GPIO numbers. Replace REPLACE_WITH_YOUR_SSID, REPLACE_WITH_YOUR_PASSWORD and any IP address before uploading. Select the correct board under Tools before flashing.
